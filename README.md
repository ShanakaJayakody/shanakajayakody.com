# shanakajayakody.com

Personal site of Shanaka Jayakody: educator, founder, builder.

Built with Vite + React + TypeScript. No CSS framework, no CMS: just editable TSX and CSS.

## Develop

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

Static output lands in `dist/`, ready to deploy anywhere (intended home: [shanakajayakody.com](https://shanakajayakody.com)).
